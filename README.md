# Primeiro App Android

Aplicação Android simples em Kotlin com layout XML. A tela principal possui campos de e-mail e senha e um botão. Ao pressionar o botão, o texto digitado nos dois campos é exibido em um Toast.

## Como executar

1. Abra o Android Studio.
2. Selecione **File > Open** e escolha a pasta deste projeto.
3. Aguarde o Gradle sincronizar as dependências.
4. Conecte um celular com depuração USB ou inicie um emulador.
5. Clique em **Run** (ícone de play) para instalar e abrir o aplicativo.
